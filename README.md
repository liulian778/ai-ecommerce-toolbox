# AI 电商工具箱使用说明书

## 一、工具介绍

AI 电商工具箱是一款面向电商设计师、运营、跨境卖家和内容带货从业者的 AI 商品策划工具。

工具链接：

https://ai-ecommerce-toolbox-u4qunegwdb45ay5qngcxo5.streamlit.app

目前包含两个功能：

1. 商品诊断工具
2. 商品策划生成工具

---

- 电商设计师

## 三、两个工具的区别

### 商品诊断工具

适合单个商品深度分析。

可以生成：

- 商品机会判断
- 目标用户画像
- 核心卖点提炼
- 主图视觉方向
- 短视频带货方向
- 详情页/直播卖点
- 用户顾虑分析
- 跨境平台建议
- 合规风险提醒
- Markdown / TXT 诊断报告

### 商品策划生成工具

适合多个商品批量处理。

可以生成：

- 商品标题
- 主图文案
- 商品定位
- 目标用户
- 核心卖点
- 主图方向
- 详情页结构
- 短视频卖点
- AI 主图提示词
- AI 场景图提示词
- AI 背景图提示词
- 负面提示词
- 结构化 Excel 表格

## 四、使用前准备

使用前需要准备：

1. 工具网址
2. 大模型 API Key
3. 商品基础信息
4. 如果使用批量策划工具，需要准备商品 Excel 表格

---

## 五、API Key 说明

API Key 可以理解为“调用 AI 模型的钥匙”。

本工具不会内置统一 AI 账号，需要用户填写自己的 API Key。

注意：

- 不要公开自己的 API Key
- 不要截图发送 API Key
- 不要上传包含真实 API Key 的文件
- 如果 Key 泄露，请到对应平台删除或禁用旧 Key

---

## 六、支持的模型平台

目前支持：

- 智谱 BigModel
- DeepSeek
- 豆包 / 火山方舟
- 阿里云百炼 / 通义千问
- Kimi / Moonshot

---

## 七、商品诊断工具使用步骤

1. 打开工具链接
2. 左侧选择「商品诊断工具」
3. 填写商品基础信息
4. 填写可选的竞品信息或用户评论
5. 选择市场类型、输出语言和输出模式
6. 选择模型平台并填写 API Key
7. 点击「生成商品诊断报告」
8. 下载 Markdown 或 TXT 报告

---

## 八、商品策划生成工具使用步骤

1. 左侧选择「商品策划生成工具」
2. 下载商品表模板
3. 按模板填写商品信息
4. 选择生图提示词语言
5. 上传 Excel 表格
6. 下载基础版 output.xlsx
7. 选择模型平台并填写 API Key
8. 设置本次最多处理商品数量
9. 点击「批量生成 AI 策划」
10. 下载完整版 output_ai.xlsx

---

## 十、常见问题

### 1. 为什么需要 API Key？

因为工具需要调用大模型生成内容。

### 2. API Key 会保存吗？

不会写入代码文件，只会在本次网页会话中临时记住。

### 3. 为什么生成失败？

常见原因：

- API Key 填错
- 模型名称填错
- API 地址不正确
- 账号余额不足
- 网络连接异常
- 平台服务暂时不可用

### 4. 为什么批量生成时不能切换页面？

当前版本是 Streamlit 原型工具。批量生成过程中如果切换工具、刷新页面或关闭网页，任务可能会中断。

### 5. 为什么生图提示词有中文也有英文？

商品策划生成工具里可以选择生图提示词语言：

- 中文
- English
- 中英双语

## 十一、使用建议

建议新用户按这个顺序使用：

1. 先用商品诊断工具分析一个商品
2. 再用商品策划生成工具批量处理多个商品
3. 批量生成时先测试 1-3 个商品
4. 确认输出效果后，再增加商品数量
5. 下载 Excel 后继续加工使用
