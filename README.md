# AI 电商商品诊断工具

这是一个基于 Streamlit 和大模型 API 的电商商品诊断工具。

用户只需要填写商品基础信息、目标平台、价格带、卖点、竞品信息或评论内容，就可以自动生成一份商品诊断报告，帮助电商从业者判断商品机会、目标用户、卖点方向、内容策略、主图方向和跨境平台适配建议。

---

## 一、项目简介

本工具适合电商运营、电商设计师、短视频带货从业者、跨境电商卖家使用。

它不是简单生成文案，而是围绕一个商品做完整的策划分析，包括：

- 商品机会判断
- 目标用户画像
- 核心卖点提炼
- 主图视觉方向
- 短视频带货方向
- 直播话术卖点
- 用户顾虑与评论区引导
- 跨境平台适配建议
- 合规风险提醒
- 可下载诊断报告

---

## 二、核心功能

### 1. 商品基础信息输入

支持填写：

- 商品名称
- 商品类型
- 目标人群
- 目标平台
- 价格带
- 商品风格
- 主要卖点
- 竞品信息
- 用户评论

### 2. 支持不同电商市场

目前支持：

- 中国电商
- 跨境电商
- Amazon
- Etsy
- Shopify
- TikTok Shop

### 3. 支持不同输出语言

可选择：

- 中文
- English
- 中英双语

### 4. 支持多个大模型平台

目前支持：

- 智谱 BigModel
- DeepSeek
- 豆包 / 火山方舟
- 阿里云百炼 / 通义千问
- Kimi / Moonshot
- 硅基流动 SiliconFlow
- 自定义 OpenAI 兼容接口

用户可以填写自己的 API Key 使用。

### 5. 报告下载

支持下载两种格式：

- Markdown `.md`：适合保留标题、列表、结构，方便放到 Notion、飞书文档、作品集。
- TXT `.txt`：普通文本格式，适合直接打开、复制、转发。

## 三、安装依赖

首次使用前，请先安装依赖：

```bash
pip install -r requirements.txt
```

如果没有 `requirements.txt`，可以手动安装：

```bash
pip install streamlit requests
```

---

## 四、运行方式

在项目文件夹中打开终端，运行：

```bash
streamlit run app.py
```

运行成功后，浏览器会自动打开网页。

如果没有自动打开，可以手动访问：

```text
http://localhost:8501
```

---

## 五、使用步骤

### 第一步：填写商品信息

填写商品名称、目标人群、平台、价格、风格、卖点等信息。

如果不知道怎么填，可以点击“一键填入示例”。

### 第二步：选择市场和语言

根据你的商品使用场景选择：

- 中国电商
- 跨境电商
- Amazon
- Etsy
- Shopify
- TikTok Shop

同时可以选择报告输出语言。

### 第三步：选择模型平台

选择你要使用的大模型平台，例如：

- 智谱 BigModel
- DeepSeek
- 通义千问
- Kimi
- 豆包
- 硅基流动

然后填写对应平台的 API Key。

### 第四步：生成诊断报告

点击：

```text
生成商品诊断报告
```

系统会自动调用大模型生成完整报告。

### 第五步：下载报告

生成成功后，可以下载：

- Markdown 诊断报告
- TXT 诊断报告

## 六、API Key 安全说明

请注意：

- API Key 不要截图发给别人
- 不要把真实 Key 写死在代码里
- 不要上传到公开 GitHub 仓库
- 如果 Key 泄露，请立即去模型平台官网删除或禁用旧 Key
- 删除 Key 不等于删除账户余额，余额仍然在你的账户中

本工具默认让用户自己填写 API Key，适合个人学习、内部使用和轻量商业交付。
